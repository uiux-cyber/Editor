Kinora 1.4 lets Claude design custom animation: describe it, and Claude writes it as a Motion clip that Kinora renders frame by frame on your timeline.

## What's new

- **Motion clips:** kinetic typography, 3D scenes, animated charts, physics, generative art and logo reveals, written by Claude as a short piece of code and rendered by Kinora as a transparent layer you can move, trim, layer over video and export like any clip.
- **A full motion toolkit, offline:** three.js with post-processing (bloom, film, glitch, bokeh, halftone, pixelate), GSAP with every plugin (SplitText, MorphSVG, DrawSVG, MotionPath…), PixiJS, anime.js, D3, Matter.js physics, p5.js, Lottie, noise and Rough.js, plus Kinora's typefaces.
- **Checked before it lands:** Claude's code runs first; you get a preview frame, or Claude gets the error with its line and fixes it. Changes to a clip can be undone like any edit.
- **Exact and safe:** clips run in a sealed sandbox with no network and no access to your files, in their own process, so a broken clip never freezes Kinora. Kinora controls each clip's clock, so exports match the preview frame for frame.
- Motion clips are saved as `.kmotion` files in Documents\Kinora\Motion and can be imported like any media.
- Fixed: Claude could stop receiving answers from Kinora after anything loaded inside the editor window.

Ask Claude in Claude Desktop, for example: "Make a 6-second 3D logo reveal with bloom" or "Turn these numbers into an animated bar chart".

## Installing

Kinora 1.2 and later update themselves (or use Help → Check for updates…). New users: download **[Kinora-Setup-1.4.0.exe](https://github.com/uiux-cyber/Editor/releases/download/v1.4.0/Kinora-Setup-1.4.0.exe)**. The installer is not code-signed yet, so Windows may say it "protected your PC". Click **More info**, then **Run anyway**.
