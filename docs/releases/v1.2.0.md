Kinora 1.2 keeps itself up to date. From this version on, new releases download in the background and install when you restart, so new features and fixes reach you without visiting this page again.

## What's new

- **Automatic updates:** Kinora checks for new versions shortly after it starts and every few hours, downloads them in the background and verifies each download before use.
- **Update button:** when an update is ready, an Update button appears in the title bar with what's new. Restart now, or it installs the next time you close Kinora. Unsaved work and running exports are always dealt with first.
- **Check for updates** in the Help menu, and a new **Settings → Updates** page to check by hand, read release notes, or turn automatic updates off.
- Kinora is now open source under the MIT License.

## Installing

Download **[Kinora-Setup-1.2.0.exe](https://github.com/uiux-cyber/Editor/releases/download/v1.2.0/Kinora-Setup-1.2.0.exe)** (AI models included). Coming from Kinora 1.1 or 1.0? Install this version once by hand; after that, updates arrive on their own. Your projects are separate files and aren't affected.

The installer is not code-signed yet, so Windows may say it "protected your PC". Click **More info**, then **Run anyway**.
