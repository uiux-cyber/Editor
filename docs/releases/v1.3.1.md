Kinora 1.3.1 makes connecting Claude a single click, and fixes connecting to newer versions of Claude Desktop.

## What's new

- **One-click Connect:** **Connect Claude** (on the start screen, in Settings → Claude, or Help → Connect to Claude…) now opens Claude Desktop's own Install dialog for the Kinora extension. Click **Install** and ask Claude about your project: no restart, no config files.
- **Fixed:** in Kinora 1.3.0, Connect wrote Claude Desktop's config file, but newer Claude Desktop versions keep that file somewhere else, so Claude never saw Kinora. Connect now uses Claude Desktop extensions, which work wherever Claude keeps its settings. The old entries 1.3.0 wrote are removed automatically.
- **Always current:** the extension runs the Claude connector that comes with your installed Kinora, so Kinora's updates keep it up to date.
- **See the connection:** Settings → Claude shows whether Claude is connected now, or when it last used Kinora.

If you clicked Connect in 1.3.0, click it once more after updating and choose **Install** in Claude Desktop.

## Installing

Kinora 1.2 and 1.3 update themselves to this version (or use Help → Check for updates…). New users: download **[Kinora-Setup-1.3.1.exe](https://github.com/uiux-cyber/Editor/releases/download/v1.3.1/Kinora-Setup-1.3.1.exe)**. The installer is not code-signed yet, so Windows may say it "protected your PC". Click **More info**, then **Run anyway**.
