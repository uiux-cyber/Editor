Kinora 1.3 works with Claude. Connect it once, then ask Claude, in your own Claude app, to edit, caption and export your videos in Kinora.

## What's new

- **Kinora + Claude:** Settings → Claude → **Connect** adds Kinora to Claude Desktop in one click (Claude Code gets a ready-to-copy command). Then ask things like "cut the silences and add captions" or "export this for TikTok and YouTube Shorts".
- **Claude sees your project:** it reads the timeline, looks at frames, searches the template and sticker library, and uses every command from the command palette, including captions, silence and filler removal, and exports.
- **Starts Kinora for you:** if Kinora is closed when you ask, Claude opens it.
- **You stay in control:** each change Claude makes is one step in History, labelled "Claude: …". Replacing a file on disk always asks you first, and Claude never deletes files. The title bar shows when Claude is connected and what it's doing; one switch turns it off.
- **Private:** Claude talks to Kinora through a local connection only your Windows account can use. It runs on your Claude plan; Kinora uploads nothing and needs no API key.

Everything is in [the guide](https://github.com/uiux-cyber/Editor/blob/main/docs/CLAUDE-CONNECTOR.md).

## Installing

Kinora 1.2 updates itself to this version (or use Help → Check for updates…). New users: download **[Kinora-Setup-1.3.0.exe](https://github.com/uiux-cyber/Editor/releases/download/v1.3.0/Kinora-Setup-1.3.0.exe)**. The installer is not code-signed yet, so Windows may say it "protected your PC". Click **More info**, then **Run anyway**.
